# Petrol Transport Inc. Website

California crude oil and petroleum transportation company website. Static multi-page site with a Node dev server, build step, and verification suite.

## Commands

- `npm run dev` — Start the dev server on port 5173, serving `website/`
- `npm run build` — Build the static site into `dist/`
- `npm run preview` — Serve the built `dist/` output on port 5173
- `npm test` — Run the full verification suite (46 tests)

## Structure

- `website/` — Source of truth: HTML pages, CSS, JS, images, PDF
- `dist/` — Built output (generated by `npm run build`)
- `server.mjs` — Node static file server with directory route support
- `build.mjs` — Copies `website/` to `dist/`, adds `_redirects`, `_headers`, `404.html`
- `verify.mjs` — Tests both dev and built previews, all pages, redirects, 404, PDF checksum
- `netlify.toml` — Netlify deployment config with migration redirects

## Forms

Forms use Netlify Forms (`data-netlify="true"`). Local preview does not deliver submissions. The form service must be connected and tested before launch.

## Deployment

For static publishing, run `npm run build` and use `dist/` as the output directory. Ensure the host serves extensionless page URLs and preserves migration redirects.
