Before You Apply

The current public requirements include a valid Class A license, a clean 10-year DMV printout, two years of driving experience, required endorsements and a current medical card.

The application package contains employment and background-screening documents. Applicants should complete it carefully and return it using the process directed by Petrol Transport.
